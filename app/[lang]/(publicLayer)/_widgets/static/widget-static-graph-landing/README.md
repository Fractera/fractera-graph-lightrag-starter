# widget-static-graph-landing — the knowledge graph's landing (node step 650-4)

The home page of the knowledge graph, drawn after the Stripe sample (`fractera-stripe-starter`, `widget-static-stripe-landing`, step
573-7) like the memory, embeddings and vectors landings, so the memory elements read as one family. The page is `bare`; this widget
draws it from the items of the page data: a part is `section-head` and the items up to the next, its view chosen by its `id`
(`route` beside the hero, `solves`, `spaces` with the section `section-access-map`, `connect`, `hood`, `credits`); any other `id`
is drawn by the common view, which also draws the element's own sections (`section-metrics`, `section-cards`, `section-faq`) through the element's
`renderPage`. The words of the page the owner approved on 2026-10-19 live on in it: the pain, what a graph is, where the tokens go,
where the graph helps, the questions. Words only in the data; the machine copy comes from the items, `markdown.ts` returns nothing.
